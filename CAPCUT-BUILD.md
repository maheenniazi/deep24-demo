# CapCut build guide

You build in two passes:
- **Pass 1 = Build A (the effect).** Do this with **screen recording ON** — this footage becomes
  your tutorial b-roll.
- **Pass 2 = Build B (the tutorial).** Assemble hook + avatar intro + your screen recordings +
  captions + SFX.

CapCut buttons referenced below are the real ones from the reference: Overlay, Remove BG →
Custom removal → (Quick erase / Brush), Arrange layers, Effects, Split, Audio → Sound FX.

---

## PASS 1 — Build the effect (SCREEN-RECORD THIS)
Start your phone screen recording before you open CapCut. Work slowly and deliberately so the
b-roll is clean.

### A. Train-door reveal
1. New project, canvas **9:16**.
2. Add **clip2 (concert/fireworks)** to the main timeline — this is the base/reveal layer.
3. Tap **Overlay → Add overlay → clip1 (train doors)**. Scale it to fill the frame, covering
   clip2 completely.
4. With the door overlay selected: **Remove BG → Custom removal**.
   - Use **Quick erase** (or Brush) and **erase the glass inside both windows** so the concert
     shows through. Keep the metal door frame. Zoom in; small brush size for clean edges.
   - ⚠️ *Manual-judgment step.* Take your time on the window edges.
5. Tap **Text → Add text** → type **"day in my life"**. Style it bold/condensed, white.
6. With text selected → **layer controls → Arrange layers → move the text BEHIND the door
   overlay** (so the door frame overlaps its edges and it reads as revealed between the doors).
7. Trim so the doors **open** (clip1 motion) as the concert + text are revealed. Line the text's
   appearance up with the doors opening.

### B. Flash transition into the hero shot
8. After the reveal, add **clip3 (woman on platform)** to the main timeline.
9. Select clip3 → **Duplicate** → **Overlay** (turn the duplicate into an overlay layer).
10. Drag the overlay so it **starts slightly BEFORE** the main clip3 begins.
11. On that overlay → **Remove BG → Custom removal** → **erase everything except the subject**
    (cut the woman out from the rest of the shot).
12. **Arrange layers → move the cutout BEHIND the overlay**, then **Split** the overlay at the
    cut point.
13. **Effects → Video effects → search "White Flash" → apply** at the transition point.
14. **Audio → Sound FX →** search **"glitch"** add one, and **"camera flash"** add one — place
    both right on the flash.

### C. Sound bed (Build A)
15. **Audio → Sounds** → add an upbeat **music** track.
16. **Sound FX:** add a **train intercom** chime + a **door hiss / pneumatic** + a **whoosh**
    where the doors open. (These mirror the reference's timeline.)
17. Export this finished effect — you'll use it as the **hook** and **final reveal**.

> Stop the screen recording. You now have: (1) the finished effect clip, and (2) screen-rec
> b-roll of every step.

## PASS 2 — Assemble the tutorial
New CapCut project, 9:16. Lay these in order (full detail in SHOT-BREAKDOWN.md):

1. **Hook** — the finished effect playing + caption "how i edited this !! / train door + flash
   overlay tutorial 💥".
2. **Avatar intro** — `video-take-01.mp4` (your 4 intro lines). Add a quick train-door wipe.
3. **"let's go!!"** — a paper-tear transition.
4. **Door examples** — clip1 (+ any window/airplane shot) under "start by filming a train door…".
5. **The screen recordings** — in the step order from the breakdown, each with its caption.
6. **Final reveal** — the finished effect + "your final result should look like this".

### Captions
- Auto-caption from `tutorial_VO.mp3` (and the intro VO).
- Two styles: rounded white sans for narration + a **hand-drawn marker font** for the CAPS
  words (TRAIN DOOR, REVEALS, OVERLAY, VISIBLE, FLASH, BEHIND, SPLIT, WHITE FLASH, GLITCH).

### Audio
- Place `tutorial_VO.mp3` under the screen-rec sections; keep the music bed low under the VO.
- **Speed the VO ~1.25×** (and match clip speeds) so the whole thing lands ~50s — the reference
  runs clips at 1.2–1.3×.
- SFX: whoosh between steps, glitch + camera flash on the reveal.

### Export
- **9:16, ~50s.** Export (reference used "AI UHD" / high quality).

---

## Order of attack
1. Pass 1 (record it) → get the effect + b-roll.
2. Pass 2 → assemble + caption + audio.
3. Export → fill README reproduce-steps + comparison.md → put final MP4 in the submission folder.
