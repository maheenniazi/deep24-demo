# Comparison vs reference

**Reference:** https://www.instagram.com/reel/DdIWMjTgYvK/ (@celfstudies — train door + flash overlay tutorial)
**My version:** FINAL.mp4 · 9:16 · ~51s

## What I matched
- Overall format: a "how I edited this" tutorial teaching the train-door reveal + flash transition.
- **Opening hook** — finished edit shown inside the CapCut editor, caption "how i edited this !! / train door + flash overlay tutorial".
- **Talking-head intro** — AI avatar character (consistent across clips) in a rattan/pampas room, black off-shoulder top, plush-bunny "mic"; 4 caption beats matching the reference.
- **"let's go!!"** foil/paper-tear transition.
- **Door examples** — train doors + airplane window shade ("anything that reveals the scene").
- **Core effect** — import clips → door clip as Overlay → Remove BG → Custom Removal → erase window glass → concert/fireworks revealed through the windows → "day in my life" text placed behind the doors.
- **Flash transition** — duplicate the hero clip, extend it before the main clip, cut out the subject, arrange layers, apply White Flash, add Glitch + Camera Flash SFX.
- **Final reveal** + matching ending caption.
- **Aspect ratio (9:16) and duration (~51s)** match.
- Caption system: white narration captions + a contrasting font for emphasised words.

## What is still weaker
- **Emphasis font:** reference uses a hand-drawn marker font for the ALL-CAPS emphasis words; mine uses a serif italic — same role, different look.
- **Resolution:** exported at 720×1280 vs the reference's higher resolution, so the screen-recording sections look slightly softer.
- **Hook frame:** reference opens on the doors-opening reveal; mine opens on the concert + cutout moment of the same finished edit.
- **Assets are AI-generated / stock** (door, concert, hero) rather than personally filmed like the reference's real BART footage.
- **Weak effects** effects and transitions are weak since they were tried to be copied with little information.
